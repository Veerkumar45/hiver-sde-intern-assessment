# Dataset / attribution notes

Primary dataset specified by the assignment:
Kaggle — Thought Vector — Customer Support on Twitter
https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter

The assignment describes it as ~3M tweets and replies across dozens of brands.

For offline smoke testing this repository includes a 100-row public sample mirrored in:
https://github.com/naman-tiwari/Customer-Support-on-Twitter

The included sample is not a substitute for the full Kaggle dataset. Use the official dataset for the final assessment and respect its stated license/usage terms.
